Generate DoF selectors by excluding those DoFs in cells with material ids in the given set.

When the finite element is continuous, there will be DoFs with their support sets intersecting both the current material subdomain and the material subdomain to be excluded. Then the DoFs at the interface between them will not be selected.

Parameters
dof_handler
excluded_material_idsA set of material ids to be excluded. It can also be a map with material id as its key.
selected_dofsA vector of flags for all DoFs in the DoF handler.
reset_selectors_to_trueWhether initialize all elements in selected_dofs to true at the beginning. By default, this argument is true. When it is false, we can call this function multiple times and gradually deselect DoFs from selected_dofs.
Returns
Number of selected DoFs.

template<int dim, int spacedim, typename SearchableMaterialIdContainer >
types::global_dof_index DoFToolsExt::extract_material_subdomain_dofs_without_boundary_dofs ( const DoFHandler< dim, spacedim > &  dof_handler,
const SearchableMaterialIdContainer &  material_ids,
std::vector< bool > &  selected_dofs 
)

Generate DoF selectors by excluding those DoFs at the boundary of the material subdomain, which is specified by the given set of material ids.

When the finite element is continuous, such as FE_Q, the support sets of DoFs at the material subdomain boundary interset both the current material subdomain and its complement. This function will exclude these DoFs, since they appear in the complement material subdomain.

When the finite element is discontinuous, such as FE_DGQ, the support sets of DoFs at the material subdomain boundary are confined within the current material subdomain. This function will still select these DoFs.
