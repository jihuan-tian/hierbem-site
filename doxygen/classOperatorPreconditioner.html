Build DoF-to-cell topology for the dual space on the refined mesh.

DoF-to-cell topology will be used for building the \(\mathcal{H}\)-matrix inolving the dual space on the refined mesh.

2025-02-07 According to

References
Hiptmair, Ralf, and Carolina Urzua-Torres. 2016. “Dual Mesh Operator Preconditioning On 3D Screens: Low-Order Boundary Element Discretization.” 2016–14. CH-8092 Zürich, Switzerland: Seminar für Angewandte Mathematik, Eidgenössische Technische Hochschule.

, the dual space is \(H^{1/2}(\Gamma_{\mathrm{D}})\) in Dirichlet problem, which means the finite element basis functions do not penetrate into the adjacent subdomain \(\Gamma_{\mathrm{N}}\). If we enforce this condition by restricting the related DoF-to-cell topology within \(\Gamma_{\mathrm{D}}\), the preconditioned matrix will be ill-posed. Therefore, we remove this restriction and construct the DoF-to-cell topology by iterating over all cells in the triangulation.

Build the Galerkin \(\mathcal{H}\)-matrix for the preconditioner on the refined mesh.

This function should be called after build_mass_matrix_on_refined_mesh, since it relies on the mass matrix when building the preconditioning \(\mathcal{H}\)-matrix for the single layer potential operator.

When the preconditioner is not built on the full domain but a part of it, this flag indicates if the subdomain is an open set. If so, the DoFs at the interface (of course the finite element should have support points there) between \(\Gamma_{\mathrm{D}}\) and \(\Gamma_{\mathrm{N}}\) are not included.

If the finite element is \(L_2\) conforming, is_subdomain_open being true or false has no influence.

This variable is effective when is_full_domain is false.
