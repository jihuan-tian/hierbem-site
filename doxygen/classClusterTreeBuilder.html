Detailed Description

template<int spacedim>
class ClusterTreeBuilder< spacedim >

Class for building a cluster tree.

Here we only use the first order Lagrange mapping, i.e. MappingQ(1), for extracting coordinates of DoF support points, which is good enough for cluster partition.
