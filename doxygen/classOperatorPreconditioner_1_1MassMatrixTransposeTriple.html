Detailed Description

template<int dim, int spacedim, typename RangeNumberType>
class OperatorPreconditioner< dim, spacedim, RangeNumberType >::MassMatrixTransposeTriple

This class encapsulates the transpose of the product of three matrices: \(C_d M_r C_p^{\mathrm{T}}\), which is actually \(C_p M_r^{\mathrm{T}} C_d^{\mathrm{T}}\).
